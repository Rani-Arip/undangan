WEBSITE UNDANGAN ARIF & RANI

Isi folder:
- index.html: halaman website
- undangan-asli.jpg: foto undangan yang dikirim

Cara pakai:
1. Unggah kedua file ini ke repository GitHub yang sama.
2. Aktifkan GitHub Pages dari Settings > Pages.
3. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
4. Tunggu publikasi dan buka link GitHub Pages yang muncul.

Catatan:
- Tombol lokasi memakai pencarian Google Maps berdasarkan alamat pada foto. Sebaiknya ganti dengan tautan pin Google Maps yang tepat.
- Musik belum disertakan. Untuk musik, tambahkan file audio yang kamu punya hak/izin untuk digunakan dan ubah elemen audio di index.html.
